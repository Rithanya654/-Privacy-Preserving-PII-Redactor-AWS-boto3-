Quick Setup

  1. Download the client for your machine.
  2. Optionally download the sample ZIP if you want test input data.
  3. Download the backend ZIP and use bootstrap.sh on your EC2 instance.
  4. Launch the desktop app, enter AWS credentials, and select your ZIP of PDFs.

Notes

  • The desktop app talks to AWS at runtime, so backend access still needs to be configured.
  • The EC2 instance name tag should remain pii-redactor.
  • Run ./build_hosted_assets.sh before publishing if you are rebuilding the hosted downloads.
